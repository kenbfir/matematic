What should the ads look like as a deliverable?

For each platform (Google, Facebook, Instagram, TikTok, Yad2, WhatsApp)

A

Copy Only — Text Documents

A structured document with the exact Hebrew ad text for each platform: headlines, descriptions, hooks, CTAs. Ready to paste directly into Google Ads, Meta Ads Manager, TikTok Ads, etc.

Example: Google RSA → 15 headlines + 4 descriptions. Facebook → 3 ad variations. TikTok → script with hook/body/CTA.

B

Visual Mockups + Copy

HTML mockups showing how the ads would look on each platform (Facebook card, Instagram Reel frame, Google search result, Yad2 listing) — plus the actual Hebrew copy inside them.

Good for reviewing creative direction before handing to a designer or running.

C

Both — Copy + Visual Preview

Full ad copy documents and a visual preview page you can show anyone involved (designer, VA, ad manager) so they immediately understand the creative direction.
